              Mobile
              At 720px and below the widgets stack in one column, the queue table drops its secondary columns, and the queue is presented as a card list with expandable rows.
              
      
              
        

        

        
              
          
              Breakpoint rules
              
          
              
            
              ≤ 720px
              One column. Feed, streams, queue and health stack in that order — the queue stays the last full-width block.
              
            
              Queue columns
              Service badge, title and status survive. Quality, progress column and ETA move into the expanded row.
              
            
              Row height
              Collapsed cards are 64px tall so eight rows fit on a 667px viewport. Expanded rows grow to fit; the list never scrolls sideways.
              
            
              Touch targets
              Every control is at least 44×44px. The chevron is the only affordance on a collapsed card.
              
            
              Bottom navigation
              Five fixed destinations, always visible. The queue badge carries the paused count so the user can judge load without opening it.
